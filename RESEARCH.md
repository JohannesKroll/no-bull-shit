## Editorial boundaries

- Jellyfin is compared to Plex/Emby, not offered as a substitute for a licensed streaming catalogue.
- /e/OS is Android-based, not a universal replacement installable on any Android phone or iPhone.
- Nextcloud's open-source software does not mean hosting or administration is free.
- Office, graphics, and operating-system alternatives need compatibility checks for existing workflows.
- The ONLYOFFICE pick refers specifically to Desktop Editors; the Bitwarden pick refers to Password Manager. Other offerings and editions have different terms.
- Linux distributions can include optional proprietary firmware, drivers, or codecs.
- Git is a version-control tool, distinct from GitHub or a hosting service. Python is a language, not a direct consumer app replacement.
- Open code permits inspection; it does not alone establish security or privacy.

Individual practical caveats are stored with each project in `src/projects.js`. Official sources should be rechecked as products change.
